# Tandem-Syr — AI-платформа логопедической коррекции и инклюзивного чтения на казахском языке

**Tandem-Syr** — интеллектуальный образовательный комплекс для постановки специфических казахских фонем (**`қ, ғ, ң, ө, ү, р`**), развития речевого дыхания и адаптации учебных текстов для детей с особыми образовательными потребностями (**СДВГ, дислексия, ПДТ / ЗПР / ЕББҚ**), объединяющий в едином тандеме **логопеда, ученика и родителя**.

---

## 👥 Ролевая модель и тандем-доступ (`SQLite RBAC`)

При входе в систему пользователь авторизуется по логину и PIN-коду (или выбирает свою роль в 1 клик на экране входа):

| Роль | Демо-доступ | Основные права и возможности |
| :--- | :--- | :--- |
| 👨‍🏫 **Мұғалім / Учитель-логопед (Админ)** | `teacher` / PIN `1111` | • Свободный доступ ко всем звукам, уровням и минимальным парам<br>• Назначение индивидуального профиля адаптации (`СДВГ` / `Дислексия` / `ПДТ`) и домашних заданий<br>• Калибровка живого эталона голоса диктора (`/calibrate`) |
| 👦 **Оқушы / Ученик** | `student` / PIN `2222` | • Доступны 3 учебных и игровых модуля (кабинет логопеда скрыт)<br>• Открытие уровней `1 → 2 → 3` по мере набора звёзд (`★`)<br>• Автоматически включённый профиль лёгкого чтения (без медицинских ярлыков)<br>• Карточка домашнего задания от учителя с кнопкой «Готово!» |
| 👨‍👩‍👦 **Ата-ана / Родитель** | `parent` / PIN `3333` | • **Дневник родителя** вместо технического кабинета логопеда<br>• Просмотр прогресса ребёнка и рекомендаций логопеда<br>• Запуск домашних упражнений и адаптация текстов/учебников дома |

## 🌟 Ключевые возможности

### 1. 🎙️ Тренажёр произношения (`Дыбыс жаттығуы`)
- **Гибридный нейросетевой скоринг (`Faster-Whisper large-v3-turbo` + `Meta MMS-1B kaz`):**
  - **Лексический гейт (Whisper):** проверяет, что ребёнок произнёс именно целевое слово, а не слово-дистрактор (`кар` вместо `қар`, `ала` вместо `ара`).
  - **Акустический и фонемный анализ (MMS-1B):** извлекает 3-сегментные L2-нормализованные эмбеддинги с предпоследнего скрытого слоя (`hidden_states[-2]`) и вычисляет контрастный `ctc_margin` по вероятностям казахских фонем (`қ/к`, `ғ/г`, `ң/н`, `ө/о`, `ү/ұ`, `р/л`).
- **3 уровня сложности и система звёзд (`0..3 ⭐`):**
  - **1-деңгей (Буын / Слог):** открытые и закрытые слоги (`қа, қо, ақ, ық` и др.).
  - **2-деңгей (Сөз / Слово):** базовый словарь с детскими иллюстрациями (`қар, қол, құс, қасық` и др.).
  - **3-деңгей (Жаңылтпаш / Чистоговорки):** ритмичные фразы без ограничения по таймеру.
  - **🎯 Работа над ошибками (Минимальные пары):** автоматический подбор минимальных пар (`қал ↔ кал`, `аға ↔ ага`, `аң ↔ ан`, `ара ↔ ала`) на основе слабых звуков конкретного ученика.
- **Интерактивная 2D-биомеханическая схема артикуляции (`ArticulationDiagram.tsx`):**
  - Синхронная визуализация в двух проекциях: **сагиттальный анатомический разрез** (челюсти, твёрдое и мягкое нёбо, увула, подъязычная кость, голосовые связки, мышечный язык, поток воздуха) + **вид губ и зубов в зеркале**.
  - Пошаговый цикл из 3 фаз (*1. Дайындық → 2. Орналасу → 3. Дыбыс*), замедленный режим **`0.5x`** и наложение контура типичной ошибки (`Қ vs К`, `Р vs Л`).
- **Двухступенчатая эталонная озвучка (`GET /tts`):**
  - **Приоритет 1:** живой голос логопеда/диктора (`reference_audio/{word}.wav`), записанный в кабинете логопеда.
  - **Приоритет 2:** нейронные казахские голоса `kk-KZ-AigulNeural` и `kk-KZ-DauletNeural` (`edge-tts`) с локальным кэшированием.

### 2. 📖 Профильное адаптивное чтение (`Жеңіл оқу`)
- **3 реально различающихся профиля адаптации (`KazLLM-8B` + клиентский и серверный трансформеры):**
  - **⚡ СДВГ (`adhd`):** дробит текст по союзам и запятым на ультра-короткие динамичные микро-карточки (по 4–5 слов), отключает дефисы для быстрого слитного чтения, выделяет главное слово-якорь и показывает фокус-подсказку.
  - **🔤 Дислексия (`dyslexia`):** включает **«слоговую радугу»** (чередующаяся двухцветная подсветка слогов), увеличенный межбуквенный интервал (`tracking-[0.07em]`), тёплый кремовый фон Ирлен (`#FDF8EC`), маркировку сложных букв (`қ, ғ, ң, ө, ү, р`) и слогово-звуковой разбор трудных слов.
  - **💡 ПДТ / ЗПР (`zpr`):** лексически переписывает книжные и абстрактные обороты простым бытовым языком (**Easy-to-Read**), добавляет карточку-пояснение *«Түсіндірме / Простыми словами»*, расширенный словарик (до 3 слов) и автоматически включает замедленную озвучку **`0.5x`**.
- **Фонетически точный казахский слогоделитель (`syllable_parser.py` + клиентский фонетический делитель):**
  - Учитывает полугласную природу буквы **`у`** рядом с гласными (`ау-ма-ғы-нан`, `шар-уа-шы-лы-ғы`).
- **Распознавание фотографий учебников и PDF (`POST /ocr/extract`):**
  - Извлечение текста из цифровых PDF через `PyMuPDF (fitz)` с постраничной навигацией (`◀ 1 / N ▶`, лимит до 10 МБ / 1500 символов за урок).
  - CPU-OCR через `EasyOCR (["ru", "uk", "mn", "tjk"], gpu=False)` (0 МБ нагрузки на VRAM видеокарты) + **универсальный лингвистический пост-процессор казахского языка (`_postprocess_kazakh_ocr`)** на основе закона сингармонизма (*Үндестік заңы*: восстановление `ң, ә, ұ, ғ, қ, ө` и склейка переносов строк).

---

### 3. 🎮 5 логопедических мини-игр с DSP-фильтром голоса и дыхания (`Лого-ойындар`)
Работают в реальном времени в браузере через Web Audio API (`BiquadFilterNode 85 Hz` + расчёт нормированной автокорреляции основного тона $F_0$ и ZCR, **0% нагрузки на GPU**), отличая чистый выдох от настоящего голоса:
1. **⛵ Сырдария желкені (Парусник на Сырдарье):** тренировка плавного длительного выдоха *без участия голоса*.
2. **🚗 Моторды оталдыр (Заведи моторчик):** тренировка звонкой вибрации `[Р]` / `[Ғ]` (`«Д-р-р-р!»`) — реагирует только на голос с модуляцией огибающей.
3. **🌼 Бақбақ гүлі (Сдуй одуванчик):** 5 коротких взрывных голосовых импульсов (`«Қа! Қо! Ақ!»`) для постановки увулярной смычки `[Қ]`.
4. **🐝 Бал арасы (Пчёлка собирает мёд):** непрерывный носовой и гласный резонанс (`«Ң-ң-ң»`, `«Ө-ө-ө»`, `«Ү-ү-ү»`).
5. **🥁 Буын барабаны (Ритм-барабан по слогам):** отработка слоговой структуры многосложных слов (`Қа-ра-қар-ға`, `Қы-зыл-ор-да`, `Қо-ңы-рау`, `Кө-бе-лек`).

## ⚙️ Установка и запуск

### 1. Бэкенд (`stt-service`)
Требуется Python 3.10+ и видеокарта NVIDIA с поддержкой CUDA (веса моделей кэшируются на диск `D:\models\`).

```powershell
cd D:\tandem-syr\stt-service
python -m venv venv
.\venv\Scripts\activate

pip install torch==2.5.1+cu121 torchaudio==2.5.1+cu121 torchvision==0.20.1+cu121 --extra-index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
```

Создайте файл `D:\tandem-syr\stt-service\.env` (по образцу `.env.example`):
```env
KAZLLM_BASE_URL=http://100.91.20.87:11434
KAZLLM_MODEL=kazllm:8b
```

### 2. Фронтенд (`frontend`)
```powershell
cd D:\tandem-syr\frontend
npm install
npm run build
```

### 3. Запуск и публичная HTTPS-ссылка
- **Продакшен + публичный HTTPS-туннель (`cloudflared`):** запустите **`D:\tandem-syr\start_prod.bat`** — соберёт `frontend/dist`, поднимет единый сервер на порту `8001` и выдаст публичный `https://*.trycloudflare.com` URL (необходим для работы микрофона и камеры на смартфонах).
- **Только туннель (если порт `8001` уже запущен):** запустите **`D:\tandem-syr\start_tunnel.bat`**.
- **Режим разработки (Hot-Reload):** запустите **`D:\tandem-syr\start_tandem.bat`** (`Vite :5173` + `FastAPI :8001`).

## 🔌 Справочник основных эндпоинтов API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/auth/users` | Список пользователей и последних домашних заданий |
| `POST` | `/auth/login` | Вход по логину/PIN-коду или быстрой роли (`teacher \| student \| parent`) |
| `POST` | `/auth/student-profile` | Назначение профиля адаптации чтения ученику (`adhd \| dyslexia \| zpr`) |
| `GET` / `POST` | `/homework` | Получение списка и создание домашнего задания логопедом родителю и ученику |
| `POST` | `/homework/{id}/complete` | Отметка домашнего задания выполненным |
| `POST` | `/evaluate` | Гибридная оценка произношения (`Whisper` + `MMS-1B` эмбеддинги и CTC-логиты), расчёт `score` и `stars (0..3)` |
| `POST` | `/calibrate` | Запись живого эталона логопеда в `reference_audio/{word}.wav` и обновление `reference_embeddings.pt` |
| `GET` | `/tts` | Двухступенчатая озвучка (`voice = auto \| live \| aigul \| daulet`) с кэшированием |
| `GET` | `/llm/health` | Проверка доступности сервера Ollama с моделью `KazLLM-8B` |
| `POST` | `/adapt-text` | Адаптация казахского текста под профили `adhd`, `dyslexia`, `zpr` с кэшированием в SQLite |
| `POST` | `/ocr/extract` | Извлечение казахского текста из PDF (постранично) и фото учебников с пост-процессором сингармонизма |
| `POST` | `/progress/speech` / `reading` | Сохранение прогресса упражнений, карточек и мини-квиза |
| `GET` | `/progress/summary` / `weak-phonemes` | Сводная статистика и рекомендации минимальных пар по слабым фонемам |
