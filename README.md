# Tandem-Syr — AI-платформа логопедической коррекции и инклюзивного чтения на казахском языке

**Tandem-Syr** — интеллектуальный образовательный комплекс для постановки специфических казахских фонем (**`қ, ғ, ң, ө, ү, р`**), развития речевого дыхания и адаптации учебных текстов для детей с особыми образовательными потребностями (**СДВГ, дислексия, ЗПР / ЕББҚ**).

---

## 🌟 Ключевые возможности

### 1. 🎙️ Тренажёр произношения (`Дыбыс жаттығуы`)
- **Гибридный нейросетевой скоринг (`Faster-Whisper large-v3-turbo` + `Meta MMS-1B kaz`):**
  - **Лексический гейт (Whisper):** проверяет, что ребёнок произнёс именно целевое слово, а не слово-дистрактор (`кар` вместо `қар`, `ала` вместо `ара`).
  - **Акустический и фонемный анализ (MMS-1B):** извлекает 3-сегментные L2-нормализованные эмбеддинги с предпоследнего скрытого слоя (`hidden_states[-2]`) и вычисляет контрастный `ctc_margin` по вероятностям казахских фонем (`қ/к`, `ғ/г`, `ң/н`, `ө/о`, `ү/ұ`, `р/л`).
- **3 уровня сложности и система звёзд (`0..3 ⭐`):**
  - **1-деңгей (Буын / Слог):** открытые и закрытые слоги (`қа, қо, ақ, ық` и др.).
  - **2-деңгей (Сөз / Слово):** базовый словарь с детскими иллюстрациями (`қар, қол, құс, қасық` и др.).
  - **3-деңгей (Жаңылтпаш / Чистоговорки):** ритмичные фразы без ограничения по таймеру.
  - **🎯 Работа над ошибками (Минимальные пары):** автоматический подбор минимальных пар (`қал ↔ кал`, `аға ↔ ага`, `аң ↔ ан`, `ара ↔ ала`) на основе слабых звуков конкретного ученика.
- **Интерактивная 2D-биомеханическая схема артикуляции (`ArticulationDiagram.tsx`):**
  - Синхронная визуализация в двух проекциях: **сагиттальный анатомический разрез** (челюсти, твёрдое и мягкое нёбо, увула, подъязычная кость, голосовые связки, мышечный язык, поток воздуха) + **вид губ и зубов в зеркале**.
  - Пошаговый цикл из 3 фаз (*1. Дайындық → 2. Орналасу → 3. Дыбыс*), замедленный режим **`0.5x`** и наложение контура типичной ошибки (`Қ vs К`, `Р vs Л`).
- **Двухступенчатая эталонная озвучка (`GET /tts`):**
  - **Приоритет 1:** живой голос логопеда/диктора (`reference_audio/{word}.wav`), записанный в кабинете логопеда.
  - **Приоритет 2:** нейронные казахские голоса `kk-KZ-AigulNeural` и `kk-KZ-DauletNeural` (`edge-tts`) с локальным кэшированием.

---

### 2. 📖 Адаптивное чтение для детей с СДВГ, дислексией и ЗПР (`Жеңіл оқу`)
- **Адаптация текста через `KazLLM-8B` (Ollama) с офлайн-фолбэком:**
  - Разбивает сложные школьные параграфы на **3–6 коротких микро-карточек** (по одной простой мысли до 7–8 слов на карточку).
  - Показывает строго **по одной карточке на экране** с прогресс-баром, релевантным эмодзи, детским словариком трудных слов и финальным проверочным мини-квизом из 2 вопросов.
- **Фонетически точный казахский слогоделитель (`syllable_parser.py`):**
  - Учитывает полугласную природу буквы **`у`** рядом с гласными (`ау-ма-ғы-нан`, `шар-уа-шы-лы-ғы` — не дробит дифтонгоиды на ложные слоги).
  - Подсвечивает специфические казахские буквы (`қ, ғ, ң, ө, ү, р`) и переключает мягкий кремовый фон (`#FDF8EC`) для снижения зрительного стресса при дислексии.
- **Распознавание фотографий учебников и PDF (`POST /ocr/extract`):**
  - Мгновенное извлечение текста из цифровых PDF через `PyMuPDF (fitz)` с постраничной навигацией (`◀ 1 / N ▶`).
  - Автоматический OCR-фолбэк через `EasyOCR (['kk', 'ru'])` на CPU (`gpu=False`, 0 МБ нагрузки на VRAM видеокарты) для фотографий со смартфона и сканированных страниц (лимит файла: до 10 МБ, до 1500 символов за один урок).

---

### 3. 🎮 5 логопедических мини-игр с DSP-фильтром голоса и дыхания (`Лого-ойындар`)
Работают в реальном времени в браузере через Web Audio API (`BiquadFilterNode 85 Hz` + расчёт нормированной автокорреляции основного тона $F_0$ и ZCR, **0% нагрузки на GPU**), отличая чистый выдох от настоящего голоса:
1. **⛵ Сырдария желкені (Парусник на Сырдарье):** тренировка плавного длительного выдоха *без участия голоса*.
2. **🚗 Моторды оталдыр (Заведи моторчик):** тренировка звонкой вибрации `[Р]` / `[Ғ]` (`«Д-р-р-р!»`) — реагирует только на голос с модуляцией огибающей (от простого дутья мотор не заводится).
3. **🌼 Бақбақ гүлі (Сдуй одуванчик):** 5 коротких взрывных голосовых импульсов (`«Қа! Қо! Ақ!»`) для постановки увулярной смычки `[Қ]`.
4. **🐝 Бал арасы (Пчёлка собирает мёд):** непрерывный носовой и гласный резонанс (`«Ң-ң-ң»`, `«Ө-ө-ө»`, `«Ү-ү-ү»`).
5. **🥁 Буын барабаны (Ритм-барабан по слогам):** отработка слоговой структуры многосложных слов (`Қа-ра-қар-ға`, `Қы-зыл-ор-да`, `Қо-ңы-рау`, `Кө-бе-лек`).

---

### 4. 🩺 Кабинет логопеда (`Логопед кабинеті`)
- Индикатор статуса сервера **`KazLLM-8B`** (`ONLINE / FALLBACK`) и сводка прогресса ученика по произношению и чтению.
- Аналитика слабых фонем ученика с автоматическими рекомендациями минимальных пар и кнопкой быстрого запуска тренировки.
- **Калибровка живого эталона (`POST /calibrate`):** запись голоса логопеда с обрезкой тишины, нормализацией громкости, сохранением `.wav`-эталона в `reference_audio/` и мгновенным обновлением 3-сегментных эмбеддингов в `reference_embeddings.pt` без перезапуска сервера.

## ⚙️ Установка и настройка

### 1. Бэкенд (`stt-service`)
Требуется Python 3.10+ и видеокарта NVIDIA с поддержкой CUDA (веса моделей кэшируются на диск `D:\models\`).

```powershell
cd D:\tandem-syr\stt-service
python -m venv venv
.\venv\Scripts\activate

# Установка PyTorch с поддержкой CUDA 12.1
pip install torch==2.5.1+cu121 torchaudio==2.5.1+cu121 torchvision==0.20.1+cu121 --extra-index-url https://download.pytorch.org/whl/cu121

# Установка остальных зависимостей (FastAPI, Whisper, Transformers, EasyOCR, PyMuPDF, Edge-TTS)
pip install -r requirements.txt
```

Создайте файл `D:\tandem-syr\stt-service\.env` (по образцу `.env.example`):
```env
KAZLLM_BASE_URL=http://100.91.20.87:11434
KAZLLM_MODEL=kazllm:8b
```

Если файл эталонных эмбеддингов `reference_embeddings.pt` ещё не сгенерирован:
```powershell
.\venv\Scripts\python.exe build_references.py
```

### 2. Фронтенд (`frontend`)
Требуется Node.js 18+:
```powershell
cd D:\tandem-syr\frontend
npm install
npm run build
```

## 🚀 Запуск проекта

### Вариант А: Продакшен-режим на одном порту (рекомендуется для презентации и экономии ОЗУ)
Запустите **`D:\tandem-syr\start_prod.bat`** — скрипт соберёт фронтенд в `frontend/dist` и запустит единый сервер FastAPI, который раздаёт и веб-интерфейс, и API на одном порту:
- **Приложение и API:** `http://localhost:8001`
- **Swagger-документация API:** `http://localhost:8001/docs`

### Вариант Б: Режим разработки (с Hot-Reload)
Запустите **`D:\tandem-syr\start_tandem.bat`** — откроются два окна:
- **Фронтенд (Vite):** `http://localhost:5173`
- **Бэкенд (FastAPI):** `http://localhost:8001`

## 🔌 Справочник основных эндпоинтов API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/evaluate` | Гибридная оценка произношения (`Whisper` + `MMS-1B` эмбеддинги и CTC-логиты), расчёт `score` и `stars (0..3)` |
| `POST` | `/calibrate` | Запись живого эталона логопеда в `reference_audio/{word}.wav` и обновление `reference_embeddings.pt` |
| `GET` | `/tts` | Двухступенчатая озвучка (`voice = auto \| live \| aigul \| daulet`) с кэшированием |
| `GET` | `/tts/status` | Проверка наличия записанного живого эталона для слова (`{"has_live": bool}`) |
| `GET` | `/llm/health` | Проверка доступности сервера Ollama с моделью `KazLLM-8B` |
| `POST` | `/adapt-text` | Адаптация казахского текста под профили `adhd`, `dyslexia`, `zpr` с кэшированием в SQLite |
| `POST` | `/ocr/extract` | Извлечение казахского текста из цифровых/сканированных PDF (с выбором страницы) и фото учебников |
| `POST` | `/progress/speech` | Сохранение результата упражнения по уровням (`1..3`) и начисление звёзд |
| `POST` | `/progress/reading` | Сохранение прогресса прочитанных карточек и мини-квиза |
| `GET` | `/progress/summary` | Сводная статистика ученика по произношению и чтению |
| `GET` | `/progress/weak-phonemes` | Автоопределение слабых фонем ученика с подборкой рекомендованных минимальных пар |
